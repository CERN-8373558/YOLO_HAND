# 手语字母识别推理 Demo —— 讲解文档

> 配套脚本：`predict.py` | 模型：`runs/classify/runs/classify/asl_demo/weights/best.pt`

## 1. 推理是什么？

训练是"让模型学知识"，推理是"用学到的知识回答新问题"。

```
训练：  [A图片+B图片+C图片...]  →  模型学会"A长这样、B长这样"
推理：  模型看到一张新图  →  判断"这是 A 的概率 97%，是 T 的概率 1%..."
```

**关键区别**：推理用的图**从未出现在训练集里**，所以它能检验模型是不是真的"学会了"，而不是"背下来了"。这就是为什么用测试集单独验证。

## 2. 脚本核心逻辑（两行关键代码）

```python
model = YOLO(args.model)          # 1. 加载训练好的模型文件 best.pt
results = model(args.source, ...) # 2. 推理：喂图，得到结果
```

分类模型的推理结果 `r.probs` 是一个**概率数组**，比如：
```
A: 0.97   T: 0.01   E: 0.01   S: 0.00 ...
```
取概率最大的那个类别就是模型"最自信的答案"。

## 3. 如何读懂输出

以刚才测试为例：
```
[9] 识别结果: I  (置信度 83.99%)   ← 模型说"这是 I"，但有点犹豫
[2] 识别结果: B  (置信度 99.91%)   ← 模型非常确定
[22] 识别结果: V  (置信度 78.32%)  ← 注意下面还跟着 W 18%
```

**置信度的含义**：
- **高（>95%）**：模型很确定，基本可信
- **中（80~95%）**：大概率对，但值得留意
- **低（<80%）**：模型在几个手势间摇摆，**很可能就是相似的字母**

## 4. 有趣发现：哪些字母最容易混淆？

从测试看，模型对这几组信心最低：

| 字母 | 置信度 | 它犹豫的对象 | 为什么难 |
|------|--------|-------------|---------|
| V | 78% | W (18%) | V 和 W 都伸两指，只差手指是否分开 |
| N | 80% | M (20%) | N/M 都是握拳，只差指头位置 |
| I | 84% | R (5%) | I 和 R 都伸食指 |

**这是手语识别的天然难点**——很多字母手势在照片上极其相似。真实世界里人也容易看错。

## 5. 学习要点

1. **推理和训练是同一套 API**：`model(source)` 一条命令，内部自动处理缩放、归一化、前向传播。这就是"框架帮你封装了细节"。
2. **置信度不只是个数字**：它揭示了模型"哪里不确定"，帮我们定位数据/模型的短板。
3. **为什么不用检测框**：分类模式下整图就是一个手势，没有"定位"需求。若未来要"多个手势同时识别"，才需要检测。
4. **阈值的作用**：`--conf 0.5` 可以过滤低置信度结果，避免误报。

## 6. 常用命令

```bash
# 单张图片
python predict.py "dataset_small/val/A/A1534.jpg"

# 整个文件夹批量
python predict.py "ASL/.../asl_alphabet_test"

# 视频
python predict.py "video.mp4"

# 摄像头（0 表示第一个摄像头）
python predict.py 0

# 自定义阈值
python predict.py "图片路径" --conf 0.7
```
